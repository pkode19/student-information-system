# Student Information System

A simple Python project that collects student information and displays a well-formatted student profile.

## Features

- Collects the student's full name
- Collects the Student ID
- Collects the student's programme
- Collects the student's level
- Collects the student's age
- Collects the student's favourite programming language
- Generates a student username by combining the first three letters of the student's name with the Student ID
- Generates a student email by combining the generated username with `@st.ug.edu.gh`
- Uses string concatenation to generate the username and email
- Builds the output border using string concatenation
- Displays all student information in a clean, formatted layout
